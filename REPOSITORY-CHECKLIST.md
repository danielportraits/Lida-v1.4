# Checklist del repositorio

## Antes de subir
- [ ] Confirmar el nombre final del repositorio.
- [ ] Revisar todos los archivos y que no haya secretos.
- [ ] Probar localmente por HTTP/HTTPS.
- [ ] Probar diseño móvil, escritorio y navegación con teclado.
- [ ] Verificar consola del navegador.
- [ ] Revisar que el logo provisional no se confunda con la marca final.
- [ ] Revisar service worker después de cambios (actualizar versión de caché).

## GitHub Pages
- [ ] Subir el contenido de la carpeta a la raíz del repo.
- [ ] Configurar `main` y `/ (root)` en Settings → Pages.
- [ ] Esperar el despliegue y abrir la URL publicada.
- [ ] Probar que `manifest.webmanifest`, icono, CSS y módulos carguen bajo el subpath del repositorio.

## Antes de producción
- [ ] Backend real.
- [ ] Autenticación y autorización.
- [ ] Política de privacidad y términos.
- [ ] Pruebas automatizadas.
- [ ] Revisión de seguridad y accesibilidad.
